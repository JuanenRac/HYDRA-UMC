# Support Information 🛠️ (HYDRA-UMC)

Thank you for using the HYDRA-UMC ecosystem! Here is how you can get help with the core firmware and hardware:

## 📺 Video Tutorials & Demos
The best way to understand how to assemble and configure the hardware is through our official YouTube channel:
[youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries
For hardware licensing, professional consulting, or specific technical blockers:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports
If you found a real error in the code or hardware design, please open a **GitHub Issue** in this repository. 
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- We do not provide support for third-party hardware modifications not documented here.
- Please do not use Issues for "How to" questions.
